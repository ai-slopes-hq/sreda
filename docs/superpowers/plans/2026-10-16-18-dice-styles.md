# Plan 18 — DICE in eleven styles Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** DICE throws a patch in one of eleven styles, built from a library of randomised parts with 0–3 sound-design
twists, so throws differ in structure and timbre, not only in knob values.

**Architecture:** `packages/core/src/factory/dicepatch.ts` becomes a folder `factory/dice/`: shared types and random
helpers, an assembler (voices → mixes → the style's effect chain → OUT, frames, the clock), a parts library by role,
eleven style descriptions and eight twists. A style picks roles and parts (weighted) and an effect chain; twists then
add modules and cables between the built voices. The UI shows the style in the outer frame's name and a notice.

**Tech Stack:** TypeScript (packages/core, Vitest), the protocol package's WASM render for audio tests
(`packages/protocol/src/render.ts`), SolidJS store (`packages/ui/src/library.ts`).

**Spec:** `docs/superpowers/specs/2026-10-07-canvas-ux-design.md` §6, the **DICE** item (revision 36).

## Global Constraints

- The same seed gives the same patch (`mulberry32` from `generators.ts`; no `Math.random` inside core).
- Every throw is a valid document (`validateDoc` round-trips), has no PROBLEMS (`wireProblems(...).filter(p => !p.info)`
  is empty), exactly one OUT, and an outer frame with its own clock; sequences are META-SEQ only.
- Every throw sounds: master RMS between −40 and −3 dBFS over 4 s, never above 0 dBFS, all samples finite.
- Equal odds for the eleven styles; the outer frame is named with the style's label in uppercase
  (`ACID`, `WEST COAST`, `IDM / GLITCH`); the notice reads `Dice: <label>` (`Dice: acid`, `Dice: west coast`).
- Bass and lines share the style's scale and root.
- Voices sit in named STACK frames inside the clock frame; past four voices two MIXes in a row.
- Parameter names and option indices come from `packages/core/src/generated/specs.json` (e.g. FILTER `model`
  SVF 0 · LADDER 1 · DIODE 2 · SK 3 · COMB 4 · VOWEL 5; DELAY `type` DIGI 0 · TAPE 1 · SPRING 2; REVERB `type` ROOM 0 ·
  PLATE 1 · HALL 2; LPG `mode` VCA 0 · LP 1 · BOTH 2; OSC `wave` SIN 0 · TRI 1 · SAW 2 · SQR 3).
- `pnpm check` passes before every commit; commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- **A twist that cannot apply** (FM with only drum voices, S&H on pitch with no pitched voice): it is skipped, never
  leaves a dangling module or an empty input. Pinned in Task 5 (`every twist applies or returns null`).
- **Five or more voices** (drums + bass + line + texture + a GRAINS twist): the second MIX takes the overflow; no input
  is dropped. Pinned in Task 1 (`assemble chains a second MIX past four voices`).
- **Loudness drift across styles**: industrial (DRIVE to the edge) and drone (FOLD, long reverb) stay inside −40…−3
  dBFS and never clip. Pinned by the per-style render in Task 4.
- **Monotony inside one style**: ten throws of one style are not near-copies. Pinned in Task 5 (variety test).
- **A part alone is silent** (a pinged voice whose gate never fires at its clock ratio): every part renders sound on
  its own. Pinned in Tasks 2 and 3 (part render tests).

  ```ts
  export type Role = 'drums' | 'bass' | 'line' | 'texture';

  export type TwistId = 'fm' | 'snh' | 'switch' | 'feedback' | 'grains' | 'polymeter' | 'shaper' | 'chance';
  export interface DiceCtx { S: Builder; R: Rand; scale: number; root: number; bpm: number; x: number; y: number }
  export interface DiceVoice extends Voice {            // Voice = { ids, out, clocks } from factory/voices.ts
    name: string; role: Role; part: PartId;
    level: number;                                       // its MIX level 0…1
    seq?: string;                                        // its META-SEQ (polymeter, chance twists)
    gate?: [string, string];                             // the gate that plays it (switch, chance, snh twists)
    pitch?: [string, string];                            // an oscillator's pitch input (snh twist)
    osc?: [string, string];                              // an audio-rate oscillator output (fm twist)
    fm?: [string, string];                               // an oscillator's FM input (fm twist)
    cutoff?: [string, string];                           // a filter id and '@cutoff' (snh twist)
  }
  export type Part = (c: DiceCtx) => DiceVoice;
  export type FxChain = (c: DiceCtx, input: [string, string]) =>
    { ids: string[]; l: [string, string]; r?: [string, string]; clocks: [string, string, number][] };
  export type Twist = (c: DiceCtx, voices: DiceVoice[]) => { ids: string[]; clocks: [string, string, number][];
    extraVoice?: DiceVoice } | null;   // null: not applicable to these voices
  export interface Style {
    id: DiceStyleId; label: string; bpm: [number, number]; scales: number[];
    roles: { role: Role; p: number; parts: [PartId, number][]; count?: [number, number] }[];
    fx: [FxChain, number][]; twists: [TwistId, number][]; twistCount: [number, number];
  }
  ```

- Produces (index.ts): `dicePatch(specs: Specs, seed: number): { doc: Doc; style: DiceStyleId; label: string;

### Task 5: Twists, variety, docs

**Files:**
- Create: `factory/dice/twists.ts`
- Modify: `factory/dice/index.ts`, `dice.test.ts`, `packages/protocol/src/dicepatch.test.ts`, `docs/ROADMAP.md`,
  `docs/backlog.md`

**Interfaces:**
- Consumes: `DiceVoice` fields from Tasks 2–3.
- Produces: `TWISTS: Record<TwistId, Twist>`.

Twists (each returns null when the voices lack what it needs): `fm` — a voice's `osc` into another pitched voice's
`fm` input (OSC `fmi` 0.1–0.4 or COMPLEX via `@index`), never into itself; `snh` — NOISE white → S&H `in`, S&H `trig`
from a voice's `gate`, S&H `out` into another voice's `pitch` (at an attenuverter 0.05–0.15) or its `cutoff`
(0.2–0.4); `switch` — a SPREAD (`mode` SEQ or RAND, `len` 2–4) sends one voice's `gate` alternately to two voices'
`gate` targets, replacing their own gate cables; `feedback` — the style's DELAY (or a new DELAY DIGI on the mix)
feedback 0.7–0.85 with a FILTER bp in the loop; `grains` — GRAINS LIVE fed by a pitched voice, its `l` returned as an
`extraVoice` (role texture, level 0.4); `polymeter` — 1–3 voices' GATE or NOTE lane lengths set to 5, 7, 9, 11 or 13;
`shaper` — a DRIVE or FOLD inserted after a voice's out (the voice's out moves to the shaper); `chance` — CHANCE `p`
0.4–0.75 between a voice's clock and its seq (`clk`), as today's ambient bells do. `index.ts` picks `twistCount`
twists from the style's pool with `weighted` (no repeats), applies them in order before `assemble`, and records
the ones that did not return null in `twists`.
