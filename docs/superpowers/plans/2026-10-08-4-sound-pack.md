# SREDA 2 · Plan 4 — The sound pack

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Milestone 2 (spec §7a): DRIVE, the FILTER models, the DELAY types, REVERB with its room display, samples as a
system (library folder, decoding, a pool in the engine, the SAMPLES picker, drop to load), SAMPLER and GRAINS — each
slice audible as soon as it lands.

**Architecture:** every module stays one Rust file (or a folder for FILTER and REVERB) with `spec()` + DSP + tests,
drawn by the generic panel; new displays (room, wave, grains) are Solid components fed by the live readout loop.
Samples are decoded in the renderer (Web Audio, resampled to the engine's rate), sent to the worklet as transferred
`Float32Array`s and kept in a pool in the engine by a session-local numeric id; a module's document holds the
sample's library path, and `compile` maps it to the id the engine reads from the module's fixed values.

**Tech Stack:** as Plans 1–3. New: `OfflineAudioContext.decodeAudioData` for decoding and resampling; Electron
`webUtils.getPathForFile` for dropped files.

**Spec:** `docs/superpowers/specs/2026-10-07-canvas-ux-design.md` §7a (the table and every bullet), §2 (panel grammar),
§3 (roles), §4 (picker), §5a (PROBLEMS), §6 (library), §8 (engine), §9 (NaN guard); the prototype board
`docs/prototype/SoundPack.dc.html` (`DEFS` from line 214: panel layouts; `roomPaths` from line 228: the room display;
`sampleDisplay`: the wave and grains displays).

## Global Constraints

- Everything in Plans 1–3's Global Constraints holds: the audio-thread rules in `CLAUDE.md`; nothing allocates in
  `process` (buffers, voices, grain pools and the 8 s live buffer are allocated on construction; the sample pool on
  load, in a message handler, never in `process`); any sample rate; knobs glide 10 ms; NaN → 0 and reset.
- Sizes (HP × U) and port / knob / mode-strip lists are exactly §7a's table; port labels ≤ 5 characters.
- Nonlinear stages (DRIVE, FILTER DRV) use first-order ADAA with real 2× oversampling (a half-band FIR decimator) —
  this also closes the backlog item "the folder's 2× oversampling is a no-op" (FOLD and COMPLEX move to the same
  oversampler).
- Stereo outputs are two mono outputs `l`, `r`; cables stay mono.
- Sample files: `samples/**` in the library folder, extensions `.wav .aif .aiff .flac .mp3 .ogg`; at most 10 minutes
  per file (longer: refused with a notice); more than two channels: the first two.
- Every new module: its spec fits its size (`layoutPanel(spec).fits`), it gives the same output per block and per
  sample (`Bench::blockwise_equals_per_sample`), and the all-types fixtures (`plan-all-a/b.json`, regenerated) keep
  `alloc.rs` at zero allocations and `realtime.rs` under its budgets.

## Decisions this plan makes (the spec is silent; recorded in the spec when the plan lands)

- **A module's sample** is `ModuleDoc.sample?: string` (a library path under `samples/`); old documents have none.
- **Sample ids** are session-local integers (≥ 0) handed out by the UI's sample registry; the plan carries a module's
  id (or −1) as its last fixed value; the engine keeps samples by id and a module reads the pool every block, so a
  sample arriving after the plan just starts sounding.
- **DELAY's output `out` is renamed `l`** (a new `r` beside it); `validateDoc` migrates old cables (as it migrates
  `sah` → `snh`).
- **Hits for AUTO** are found in TS once per load (spectral-flux onsets with a strength each) and sent with the sample;
  SENS (the SLICES knob while AUTO) keeps the hits whose strength is at least `1 − SENS`.
- **Audition** (↑ / ↓ in the SAMPLES tab) is an engine message that plays a sample in place of the speakers' mix,
  through the master stage, like listen.
- **Readouts:** REVERB's `state()` is its tail level (0…1); SAMPLER's `state()` is the playhead (0…1 of the file, −1
  idle); GRAINS uses a trace: `[0]` the write head (0…1, −1 when not recording), `[1…64]` grain positions (−1 empty),
  `[65…320]` 256 column peaks of the live buffer.

## Review Focus

1. **Engine rates and file rates that differ** (44.1 k engine, a 96 k file, a 22.05 k file): SAMPLER at PITCH 0 plays
   at the file's pitch and length; GRAINS likewise (tests in Tasks 7 and 9).
2. **Switching MODEL / TYPE / MODE while sound runs** (FILTER at RES 1, DELAY with FB 0.95, REVERB with FREEZE on):
   output stays finite and ≤ 1 after the master, with no step above 0.5 between samples (tests in Tasks 2, 4, 5).
3. **A sample replaced, shortened or missing while voices play it**: no out-of-range read (no panic), voices end or
   wrap within the new length, a missing sample is silence plus `MISSING · <name>` and a PROBLEMS row (Tasks 7–9).
4. **Odd files**: zero frames, one frame, 6 channels, a corrupt header, an 11-minute file — each refused or clamped
   with a notice, none crashes the UI or the engine (Task 7).
5. **Old documents**: a Plan 3 patch with FILTER (4×1, no DRV / MODEL) and DELAY `out` cables opens with the same
   sound (SVF, DIGI at CHAR 0, PING off) and its cables on `lp` / `l` (Tasks 2 and 4).

## Stage E1 — shaping

### Task 1: The 2× oversampler, ADAA curves, DRIVE

**Files:** `engine/src/shaping.rs`, `engine/src/modules/{drive.rs,fold.rs,complex.rs,mod.rs}`, `registry.rs`;
`packages/core/src/generated/specs.json`; `packages/ui/src/canvas/glyphs.ts` (none needed: DRIVE's MODE is a word
list).

**Interfaces:**
```rust
pub struct Os2x { /* 31-tap half-band FIR, polyphase */ }
impl Os2x { pub fn new() -> Self; pub fn up(&mut self, x: f32) -> [f32; 2]; pub fn down(&mut self, y: [f32; 2]) -> f32; pub fn reset(&mut self) }
pub trait Curve { fn f(x: f64) -> f64; fn big_f(x: f64) -> f64 /* antiderivative */ }
pub struct Tanh; pub struct Asym; pub struct Clip;            // SAT, OD, FUZZ
pub struct Adaa1<C: Curve> { /* x[n−1], F(x[n−1]) */ }
impl<C: Curve> Adaa1<C> { pub fn new() -> Self; pub fn process(&mut self, x: f64) -> f64; pub fn reset(&mut self) }
```
Curves: SAT `tanh x` (F = ln cosh x); OD `x ≥ 0: tanh x; x < 0: tanh(1.6 x) / 1.6` plus a +0.1 bias before and the
output DC removed (one-pole 5 Hz high-pass); FUZZ `clamp(x + 0.3, −1, 1)` (F piecewise), bias removed the same way.
ADAA falls back to `f((x + x1) / 2)` when `|x − x1| < 1e-5`.

DRIVE (§7a): `in (audio)` → `out (audio)`; knobs GAIN 0…24 dB (lin in dB, default 6), TONE 0…1 (default 0.5: a tilt
around 800 Hz, ±6 dB at the ends), MIX 0…1 (default 1); option MODE SAT / OD / FUZZ (default OD); size 5×1. Signal:
`x · g` → 2× up → `Adaa1<curve>` on both sub-samples → down → tilt → level compensation `1 / (1 + 0.6·(g − 1))^0.5`
where `g` is the linear gain → `mix`.

    fundamental; output finite for a 1e6 input; blockwise equals per sample.

### Task 3: FILTER COMB and VOWEL

## Stage E3 — time

### Task 4: DELAY types, CHAR, PING, CLK, stereo out

**Files:** `engine/src/modules/delay.rs`; `packages/core/src/{doc.ts,factory/projects.ts,factory/groups.ts}`.

Spec (§7a): size 6×1; inputs `in (audio)`, `clk (trigger)`; knobs TIME (0.001…2 s exp, as now), FB (0…0.95), MIX,
CHAR (0…1, default 0); options TYPE DIGI / TAPE / SPRING (default DIGI), PING OFF / ON (default OFF); outputs `l`,
`r`.

- DIGI: clean; CHAR → bit depth `16 − 12·CHAR` bits and a sample-and-hold rate reduction `1 + 15·CHAR²`, on the wet
  signal.
- TAPE: read position modulated by wow (0.6 Hz) and flutter (7 Hz) of depth `CHAR · (2 ms, 0.15 ms)`; tanh
  saturation and a one-pole low-pass in the feedback path, cutoff `12 kHz · (1 − 0.8·CHAR)`.
- SPRING: the wet path through 12 first-order allpasses (coefficient 0.6 + 0.3·CHAR) with a slow random modulation of
  their coefficients by CHAR (the drip).
- PING: two lines; the input feeds L, L's output feeds R, R's output feeds L (× FB); without PING `r = l`.
- CLK patched: the period between the last two rises (as `TriggerInput` measures) sets TIME to the division nearest
  the knob among `period · {1/16, 1/8, 1/4, 1/2, 1, 2, 3, 4}`, gliding 10 ms; TIME's knob still picks among them.
- Old documents: cables from a DELAY's `out` move to `l` (`validateDoc`); factory patches use `l`.

- [ ] **Step 1: Failing tests:** an impulse at TIME 0.25 s returns at 12 000 ± 2 samples (DIGI), and at 11 025 ± 2 at
  44.1 k; FB 0.5 → each repeat −6 dB ± 0.5; PING: repeats alternate L, R, L (the R repeat's index 2 × TIME); TAPE at
  CHAR 1: the 3rd repeat of a 5 kHz burst is ≥ 12 dB quieter than at CHAR 0; DIGI at CHAR 1 on a sine has ≥ 20
  distinct output levels and < 40; CLK at 0.5 s period with the knob at 0.24 s → repeats every 12 000 ± 2 samples

### Task 5: REVERB — ROOM, HALL, PLATE, FREEZE

**Files:** `engine/src/modules/reverb/{mod.rs,fdn.rs,plate.rs}`, `registry.rs`.

Spec (§7a): size 6×2 with a display of 2 lanes (kind `room`); input `in (audio)`; knobs SIZE (0…1, 0.5), DECAY
(0.1…30 s exp, 2), DAMP (0…1, 0.4), PRE (0…0.25 s, 0.01), MOD (0…1, 0.2), MIX (0…1, 0.35); options TYPE ROOM / PLATE
/ HALL (default ROOM), FREEZE OFF / ON; outputs `l`, `r`. `state()` = the tail level (RMS of the wet signal over the
