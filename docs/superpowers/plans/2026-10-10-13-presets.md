# More factory presets — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans.

**Goal:** 13 new factory groups and 4 new projects (spec revision 31, §6).

**Architecture:** `packages/core/src/factory/voices.ts` — one builder per voice (`(S, x, y) → { ids, out, clocks }`),
so groups (a voice in a frame with its own clock) and projects (voices, a mix, effects, an OUT under a clock frame)
share them. Group definitions return their main output for tests.

## Global Constraints

- Every group, wired from its main output into an OUT, and every project renders 4 s at an RMS between −40 and −3 dBFS,
  never above 0 dBFS, all finite; documents valid, no PROBLEMS other than "sound does not reach any OUT" for groups.
- Factory names lower-case as the existing ones; frame names upper-case.
